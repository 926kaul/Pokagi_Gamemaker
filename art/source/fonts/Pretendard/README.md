# Pretendard

Pokagi UI font source files. The game uses the static TTF builds from the
official Pretendard 1.3.9 release:

- `Pretendard-SemiBold.ttf`: primary UI (`Font5`)
- `Pretendard-Regular.ttf`: secondary UI (`Font6`)

Pretendard is distributed under the SIL Open Font License 1.1. See
`LICENSE.txt` in this directory. The font resources also keep a copy of the
matching TTF beside each GameMaker font asset so the atlas can be regenerated
without relying on a machine-specific font file.

Official project: https://github.com/orioncactus/pretendard
