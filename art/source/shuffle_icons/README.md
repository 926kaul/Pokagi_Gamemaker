# Pokémon Shuffle icon sources

This directory contains the 151 base-form icon files named `Shuffle001.png` through `Shuffle151.png`.

- Source category: https://archives.bulbagarden.net/wiki/Category:Shuffle_icons
- Retrieved: 2026-09-24
- Original dimensions: 256x256 PNG
- Download method: Bulbagarden Archives MediaWiki API (`imageinfo` original URLs)
- Naming rule: only exact `ShuffleNNN.png` files were downloaded; alternate forms, Mega forms, costumes and expression variants were excluded.

Bulbagarden describes these files as artwork from a Pokémon game, or substantially derived from it, and labels them as fair-use game artwork. These files should remain limited to the non-commercial fan-game context already documented by the project.

The existing GameMaker `Pokemon` sprite has not yet been overwritten. Keep this source directory intact so the imported sprite frames can be regenerated or audited later.
